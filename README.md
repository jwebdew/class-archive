# CLASS ARCHIVE

웹·디자인 교육 자료를 위한 반응형 아카이브입니다. Node.js 20의 기본 모듈로 만든 서버와 로컬 파일 저장소를 사용하므로 별도 패키지 설치가 필요 없습니다. 서버가 인증과 비공개 자료 접근을 검사하고, 비밀번호는 scrypt 해시로 보관합니다.

## 실행

PowerShell에서 이 폴더로 이동한 뒤, 12자 이상의 관리자 비밀번호를 직접 설정하고 실행합니다.

```powershell
$env:ADMIN_PASSWORD = '여기에-긴-관리자-비밀번호'
npm start
```

브라우저에서 http://127.0.0.1:3000 을 열고 푸터의 Admin Login을 선택합니다. 설정한 관리자 비밀번호로 로그인한 후 공지와 자료를 등록하세요. 자료마다 다운로드 비밀번호를 지정해야 하며 여러 파일을 첨부할 수 있습니다. 처음에는 실제 파일이 없으므로 자료 목록이 비어 있습니다.

선택 환경변수: `PORT`는 기본 3000, `HTTPS=true`는 HTTPS 리버스 프록시 뒤에서 보안 쿠키를 사용합니다. 실제 비밀번호는 소스에 넣지 마세요. 데이터는 `data/archive.json`, 파일은 `uploads/`에 저장됩니다. 두 폴더를 함께 정기적으로 백업하세요.

## 확인

관리자에서 공개 자료와 파일을 등록한 후 메인 화면에서 필터와 검색을 사용합니다. 잘못된 비밀번호는 거부되고 올바른 비밀번호로 파일을 내려받을 수 있습니다. 비공개 자료는 공개 목록과 다운로드에서 제외됩니다. 관리자 로그인 없이 관리 API에 접근하면 401이 반환됩니다.

## 운영 전 설정

기본 서버는 로컬 접속 전용입니다. 외부 수강생에게 제공하려면 HTTPS 리버스 프록시, 안전한 비밀 관리, 영구 디스크 및 백업을 갖춘 서버에 배포하고 네트워크 바인딩을 환경에 맞게 설정해야 합니다. 현재 세션과 시도 제한은 서버 메모리에 저장되므로 서버 재시작 시 초기화되며, 다중 서버 배포에는 공유 세션 및 속도 제한 저장소가 필요합니다. 요청 전체 크기는 220MB로 제한됩니다. 파일은 서버의 비공개 디렉터리에 저장되며 인증된 요청으로만 제공됩니다.
